# 발그림 이미지 폴더 (`public/images/`)

이 폴더는 **사용자가 직접 그린 패러디 발그림**만을 보관합니다.

## 파일 이름 규칙

`src/data/quizData.json` 의 각 항목은 `imageUrl` 필드를 가집니다.
기본값은 다음과 같이 매겨져 있습니다:

```
/images/movie_001.png
/images/movie_002.png
...
/images/movie_030.png
```

이 파일들을 본 폴더에 채워 넣으면 자동으로 화면에 표시됩니다.
파일이 없으면 앱은 자동으로 `badDrawingPrompt`(발그림 설명문)를 보여주는
폴백 박스를 렌더합니다.

## 추천 형식

- 형식: `.png` (투명/픽셀 느낌이면 더 좋음)
- 권장 크기: 480 × 360 ~ 720 × 540
- 스타일: MS Paint 마우스 그림, 5분 안에 그린 듯한 발그림
- 색상: 8 ~ 16색 정도면 충분

## ⚠️ 저작권 경고 — 반드시 읽어주세요

이 프로젝트의 가장 중요한 규칙입니다.

**다음은 절대 사용하지 마세요:**
- 영화 포스터, 공식 스틸컷, 예고편 캡처
- 배우 사진, 감독 사진
- 영화사/스튜디오 로고
- 캐릭터의 공식 일러스트
- 인터넷에서 다운로드한 이미지를 그대로 활용

**오직 다음만 사용하세요:**
- 본인이 직접 그린 패러디 그림 (마우스/트랙패드/태블릿)
- AI 그림 도구로 생성한, **저작권 침해가 아닌 추상적/막대인간/도형 위주**의 표현
- 명백히 "발그림"임이 한눈에 느껴지는 단순화된 표현

원본 영화 이미지를 트레이싱하거나 색만 바꾸는 것도 금지입니다.
의심스러우면 그리지 마세요. 발그림은 발그림다워야 합니다.

문제가 생기면 즉시 해당 파일을 폴더에서 삭제하세요.
